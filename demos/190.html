Polynomial removal fails for ordered binary matrices (conceptual, result 190)

Explores why a (66\times66) zero–one pattern can be far from avoidable by edits while its induced ordered copy count is below every proposed polynomial bound (c\varepsilon^C n^{132}).

Context

An induced ordered copy of a fixed binary pattern \(P\) selects increasing rows and increasing columns so that every selected entry, zero or one, agrees with \(P\). A matrix is \(P\)-free if it has no such copy. The removal question asks whether matrices with few copies can be made \(P\)-free by changing few entries. Result 190 disproves this for one explicit \(66\times66\) pattern: for every \(c,C>0\) and every \(\varepsilon>0), there is an (n\times n) binary matrix at normalized edit distance at least (\varepsilon) from being (P)-free, yet containing fewer than (c\varepsilon^C n^{132}) induced ordered copies. The exponent (132=2\cdot66) is the order of the number of possible row/column choices.

Relevance

This refutes polynomial removal in the ordered binary-matrix setting: edit distance and copy count need not be polynomially related. A matrix can be (\varepsilon)-far from pattern-free while its copy density is arbitrarily smaller than any bound (c\varepsilon^C). The demo lets you choose the constants (c,C), the distance (\varepsilon), the gap in copy density, and (n), then checks the inequality and plots the parallel (n^{132})-scale growth curves.
