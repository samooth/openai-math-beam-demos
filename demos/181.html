The Erdős–Gallai cycle-decomposition conjecture (conceptual, result 181)

Interactive illustration: decompose the edges of a random graph into edge-disjoint simple cycles and single edges.

Context

The Erdős–Gallai cycle-decomposition conjecture asks whether every finite simple undirected graph on \(n\) vertices can have its edges partitioned into \(O(n)\) simple cycles and single edges. Result 181 proves that this is true: there is an absolute constant \(C>0) such that every graph on (n) vertices admits an edge-disjoint decomposition into at most (Cn) pieces, each either a simple cycle or a single edge. The theorem includes dense graphs, where the number of edges can be (\Theta(n^2)), so the linear bound is nontrivial. The optimal constant is not determined.

Relevance

This resolves a classical problem in graph decomposition and shows that edge sets of arbitrary graphs have linear cycle complexity. It is useful for structural graph theory, for reducing global edge structure to a bounded number of cyclic and trivial pieces, and for understanding how dense graphs can still be covered by few simple cycles. The demo illustrates the decomposition greedily on small random graphs; it is conceptual and does not compute the optimal constant.
