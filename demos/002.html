BSD formula: elliptic curve invariants (result 002)

Interactive short Weierstrass curve E: y² = x³ + a x + b. Sliders change a, b; the demo computes invariants and an L(1) approximation.

Context

Proves the full Birch–Swinnerton-Dyer leading-term formula for every elliptic curve over ℚ whose full q-power Selmer group has corank 0 or 1 for some prime q, including finiteness of the Tate–Shafarevich group. The BSD conjecture links analytic data (L-value / derivative at s=1) to arithmetic data (rank, regulator, torsion, Tamagawa numbers, |Sha|).

Relevance

With result 006, this gives full BSD for a density-one set of quadratic twists of every elliptic curve over ℚ. This demo visualizes the curve and its basic invariants (discriminant, j-invariant) and approximates L(E,1) via the Euler product.
