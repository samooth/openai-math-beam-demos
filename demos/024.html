Number of totients V(x)

V(x) counts the distinct values taken by Euler's totient φ. We compute V(x) for small x and plot V(cx)/V(x), which tends to c (regular variation).

Context

Gives an asymptotic equivalent for V(x), the number of distinct totient values up to x, with a positive bounded phase-dependent factor determined by convergent arithmetic approximations. In particular V(cx)/V(x)→c for every fixed c>0, answering Erdős and Hall's scaling question.

Relevance

Resolves the regular-variation question for the totient-value counting function, linking the distribution of distinct φ-values to a clean linear scaling law.
