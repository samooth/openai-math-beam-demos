Quasipolynomial algorithms for mean-payoff, stochastic and parity games (conceptual, result 104)

Deterministic algorithms use $2^{O((\log(L+2))^2)}$ bit operations for complete binary input length $L$. They compute exact values and optimal positional strategies in ordinary mean-payoff games, the nonnegative expectation-of-liminf value set in turn-based stochastic games, and the winning set for nonnegative liminf mean payoff conjoined with parity. Slide the parameters to generate a small game, iterate the Shapley operator, and watch the quasipolynomial bound grow with input length.

Context

Gives deterministic algorithms using $2^{O((\log(L+2))^2)}$ bit operations, for complete binary input length $L$, for ordinary mean-payoff games and two separate extensions. They compute exact values and optimal positional strategies in ordinary games, the nonnegative expectation-of-liminf value set in turn-based stochastic games, and the winning set for nonnegative liminf mean payoff conjoined with parity. Signed rewards, rational chance probabilities, and parity priorities are unrestricted and binary-encoded. The Lean formalization checks a finite counterexample to a proposed optimization step in Truffet's elimination procedure and a randomized quasipolynomial mean-payoff algorithm succeeding with probability at least $7/8$.

Relevance

Provides deterministic quasipolynomial-time algorithms for mean-payoff games and their stochastic and parity extensions, closing the gap between polynomial heuristics and exponential worst-case solvers. Exact rational values and optimal positional strategies are obtained within $2^{O((\log(L+2))^2)}$ bit operations, with unrestricted signed rewards and binary-encoded inputs. A randomized variant is always correct after independent repetition with the same expected quasipolynomial bound.
