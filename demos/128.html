A factor-two approximation for shortest common superstring (conceptual, result 128)

Gives a deterministic polynomial-time algorithm constructing a common superstring of length at most twice the optimum for every finite family of explicitly represented strings. The running time is polynomial in the full encoded input length, including symbol labels.

Context

The shortest common superstring problem asks for a shortest string containing every input string as a contiguous substring. Result 128 gives a deterministic polynomial-time algorithm, for explicitly represented strings, whose output length is at most twice the optimum. Its construction uses forced occurrence counts, a balanced hierarchical graph, layers, and a connection procedure whose extra cost is bounded by the same lower bound.

Relevance

This settles the factor-two question for polynomial-time superstring approximation in the positive: the output is guaranteed within a factor of $2$ of the optimum, with running time polynomial in the full encoded input size. The interactive model below computes exact optima for small instances by dynamic programming, compares a greedy merge heuristic, and shows the cycle-cover lower bound, illustrating why the guarantee is nontrivial.
