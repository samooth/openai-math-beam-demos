Barnette's Hamiltonian-cycle conjecture (conceptual, result 180)

Tests Hamiltonicity on cubic bipartite planar 3-vertex-connected graphs: every such graph contains a cycle visiting each vertex exactly once, and even one avoiding a prescribed edge.

Context

Barnette's conjecture asks whether every finite simple cubic bipartite planar (3)-vertex-connected graph is Hamiltonian. Result 180 proves it: every such graph has a Hamiltonian cycle. Equivalently, in the dual triangulation the vertices can be partitioned into two sets, each inducing a tree; this also gives single-edge avoidance, so a Hamiltonian cycle exists that avoids any specified edge, and every three-edge path in a finite simple cubic (3)-vertex-connected Pfaffian bipartite graph lies in a Hamiltonian cycle. The proof works for all face sizes and does not assume bounded face lengths.

Relevance

This resolves a classical polyhedral Hamiltonicity problem and separates it from Tait's disproved conjecture for general cubic polyhedral graphs. It turns a long-standing existence question into a theorem with a single-edge strengthening, useful for cycle covers, facet enumeration, and structural graph theory. The demo illustrates the property on prism graphs, which are cubic, bipartite, planar, and (3)-connected, and verifies Hamiltonicity and edge avoidance constructively.
