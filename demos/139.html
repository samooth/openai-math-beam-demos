Subpolynomial queries for log-concave sampling (conceptual, result 139)

For \(C^2\) potentials with a supplied minimizer and \(I\preceq\nabla^2V\preceq2I\), sampling within total variation \(1/10\) requires only \(C_\varepsilon d^\varepsilon\) exact value-and-gradient queries for every fixed \(\varepsilon>0).

Context

Proves that for \(C^2\) potentials on \(\mathbb R^d\) with a supplied minimizer and Hessian bounded by \(I\preceq\nabla^2 V\preceq 2I\), sampling the associated log-concave distribution within total variation \(1/10\) uses only \(C_\varepsilon d^\varepsilon\) exact value-and-gradient oracle queries for every fixed \(\varepsilon>0). The bound holds on every run, with unrestricted computation between queries. A logarithmic lower bound also holds, so the optimal power-law exponent in this oracle model is zero.

Relevance

Shows that well-conditioned log-concave sampling has subpolynomial query complexity, separating oracle cost from computation: the dimension dependence of queries can be made (d^{o(1)}) while arbitrary computation is allowed between queries. This fixes the optimal power-law exponent at zero and guides the design of high-dimensional sampling algorithms.
