Perfect completeness for 2-to-1 games (conceptual, result 105)

A 2-to-1 game has constraints given by maps whose every output label has exactly two preimages. It is NP-hard, for every fixed rational $\delta\in(0,1)$, to distinguish satisfiable games (value $1$) from games whose optimum is at most $\delta$, on explicit unweighted instances with alphabet depending only on $\delta$.

Context

Khot's 2-to-1 Games Conjecture asserts that it is NP-hard to decide whether a 2-to-1 game has value close to 1 or bounded away from 1. This result proves the conjecture with perfect completeness: for every fixed rational $\delta\in(0,1)$, a deterministic polynomial-time reduction from binary 3SAT produces a nonempty unweighted game of value exactly $1$ on satisfiable inputs and at most $\delta$ on unsatisfiable inputs. Each constraint projection has exactly two preimages for every output label, the alphabet depends only on $\delta$, and the runtime is measured in the original input bit length. The Lean formalization establishes the same perfect-completeness hardness statement.

Relevance

This sharpens the hardness of approximation for constraint satisfaction and underlies reductions to problems such as vertex cover, coloring, and unique-games-type questions. Perfect completeness matters because satisfiable instances have value exactly 1, giving a clean gap without completeness error. The construction keeps instances unweighted and explicit, with a fixed alphabet per $\delta$, making the hardness result suitable as a starting point for further inapproximability reductions.
