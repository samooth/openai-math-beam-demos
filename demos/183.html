Power savings for planar halving lines and k-sets (conceptual, result 183)

Interactive illustration: for a small planar point set, count halving pairs and k-sets exactly and compare with the classical (O(n^{4/3})) and (O(n(k+1)^{1/3})) bounds.

Context

For an even set of \(n\) points in the plane with no three collinear, a halving pair is a pair whose line leaves \((n-2)/2\) points in each open half-plane. Result 183 proves an absolute power saving: the number of halving pairs is \(O(n^{4/3-\varepsilon})\) for some \(\varepsilon>0\), improving the classical \(O(n^{4/3})\) bound. More generally, for \(1\le k\le n/2\), the number of strictly separable \(k\)-subsets is \(O(n(k+1)^{1/3-\varepsilon_0})\) with an absolute \(\varepsilon_0>0). The proof is nonquantitative: the constants and positive exponents are existential. The uniform bound holds over all ranks (k), not only the middle rank.

Relevance

This is the first improvement of the exponent in the planar halving-line and (k)-set problem beyond the (4/3) barrier. It matters for combinatorial geometry, for the complexity of planar arrangements and levels, and for understanding balanced separations. The demo computes exact counts for small point sets; it does not reproduce the nonquantitative asymptotic constants.
