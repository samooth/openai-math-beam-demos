A counterexample to the Gopalan--Servedio conjecture (conceptual, result 192)

For a Boolean function $f:\{-1,1\}^n\to\{-1,1\}$, let $\widehat f(\{i\})=\mathbb E[f(X)X_i]$ and $\deg(f)$ the real multilinear degree. The demo computes these from a truth table and shows that $\sum_i \widehat f(\{i\})$ can exceed $C\sqrt{\deg(f)}$ by an arbitrary factor for suitable (large, constructed) functions.

Context

Disproves the proposed square-root bound relating a Boolean function's linear Fourier coefficients to its polynomial degree. For every $C>0$, there is a sign-valued Boolean function $f$ with $\sum_i \widehat f(\{i\})>C\sqrt{\deg(f)}$. Thus its total signed correlation with individual input bits can exceed the proposed bound by an arbitrary factor.

Relevance

Separates the conjectured square-root scale from the surviving linear bound: a linear degree bound always holds, but no constant multiple of the square-root bound does.
