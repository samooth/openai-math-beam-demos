Optimal-order randomized $k$-server on arbitrary metrics (conceptual, result 110)

A randomized $k$-server policy achieves competitive ratio $O(\log^2(k+1))$ on every metric space, matching the worst-case lower-bound order. One policy serves every finite oblivious request sequence, including on infinite and unbounded metrics.

Context

The formalization proves a randomized competitive ratio $O((\log(k+1))^2)$ for $k$-server against oblivious finite request sequences. For every $k\ge 2$, every metric space containing at least $k+1$ points, and every initial configuration, one policy works for all request sequences, including in infinite and unbounded spaces. The universal multiplicative constant is independent of the metric and $k$; the additive movement constant depends on the initial configuration and is zero when the initial server positions are distinct. On finite rational metrics, a uniform randomized bit algorithm has polynomial preprocessing and per-request bit cost polynomial in the encoded input length and $\log(t+1)$ at request $t$, with a finite instance-dependent additive movement constant.

Relevance

This matches the worst-case lower-bound order for randomized $k$-server, settling the optimal asymptotic competitive ratio on arbitrary metrics. It removes metric dependence from the multiplicative factor and handles infinite, unbounded spaces. The uniform implementation gives polynomial-time preprocessing and request processing, returning a legal server index for every request, while the additive movement constant is not claimed to be polynomially bounded.
