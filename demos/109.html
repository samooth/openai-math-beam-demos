Integer multiplication below n log n (conceptual, result 109)

Multiplies two (n)-bit integers exactly at every input length in deterministic worst-case time (O(n(\log n)^{1-\kappa})), with (\kappa=2^{-182}), on one fixed finite-alphabet Turing machine with finitely many one-dimensional tapes. This disproves the Schönhage--Strassen (n\log n) optimality conjecture in the ordinary multitape bit model. Slide the bit length and the exponent (\kappa) to compare growth rates.

Context

We give a deterministic algorithm that multiplies two (n)-bit integers in (O(n(\lg n)^{1-\kappa})) worst-case time, with (\kappa=2^{-182}), on one fixed finite-alphabet Turing machine with a fixed finite number of one-dimensional tapes. The algorithm is exact for every input length and disproves the (n\log n) optimality conjecture of Schönhage and Strassen in this model. The construction uses a fixed machine and a fixed number of tapes, so the speedup is not an artifact of varying hardware.

Relevance

This removes the long-standing (n\log n) barrier for integer multiplication in the ordinary multitape bit model and shows that faster-than-(n\log n) exact multiplication is possible with a universal constant-factor-independent asymptotic improvement in the logarithmic exponent. It affects fast arithmetic, algebraic complexity, and the design of multiplication in cryptographic and scientific software, where bit-level constants and worst-case guarantees matter.
