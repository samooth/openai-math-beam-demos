The approximation threshold for metric k-median (conceptual, result 125)

Gives a deterministic polynomial-time $(1+2/e+\varepsilon)$-approximation for finite rational metric $k$-median with specified candidate facilities, for every fixed $\varepsilon>0$. Assuming $P\ne NP$, the optimal infimum approximation factor is $1+2/e$.

Context

In metric $k$-median, given clients and candidate facilities in a metric space, choose exactly $k$ facilities minimizing the sum of each client's distance to its nearest chosen facility. Result 125 provides a deterministic polynomial-time $(1+2/e+\varepsilon)$-approximation for finite rational metrics with specified candidate facilities, for every fixed $\varepsilon>0$. Assuming $P\neq NP$, no polynomial-time algorithm can guarantee a factor below $1+2/e$, so this value is the exact approximation threshold.

Relevance

This settles the approximability of metric $k$-median: polynomial-time solutions are guaranteed within about $73.6%$ above optimum, and that constant is best possible unless $P=NP$.
