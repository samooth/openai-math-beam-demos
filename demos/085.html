Endpoint regularity of the planar centered maximal function (conceptual, result 085)

For $f\in W^{1,1}(\mathbb R^2)$, the centered disk maximal function $Mf$ satisfies $|\nabla Mf|_{L^1}\le C|\nabla f|_{L^1}$ with an absolute constant. It belongs locally to $W^{1,1}$ and has a globally integrable weak gradient. The radial model below shows how disk averaging smooths while preserving first-order Sobolev regularity.

Context

Resolves the planar centered-disk case of the Hajłasz--Onninen maximal-function regularity problem. For every real $f\in W^{1,1}(\mathbb R^2)$, the centered disk maximal function satisfies $|\nabla Mf|_1\le C|\nabla f|_1$ with an absolute constant. It belongs locally to $W^{1,1}$ and has a globally integrable weak gradient.

Relevance

Gives an absolute $L^1$ gradient bound for the planar centered disk maximal operator, settling the endpoint regularity problem in two dimensions. It shows maximal averaging does not destroy first-order Sobolev regularity, supporting harmonic-analysis arguments that require precise control of maximal functions and their derivatives.
