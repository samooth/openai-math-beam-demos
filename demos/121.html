Almost-linear approximation of edit distance (conceptual, result 121)

For every fixed rational $\varepsilon\in(0,1)$, a randomized algorithm estimates unit-cost edit distance between explicitly stored strings of total length $N$ within factor $1+\varepsilon$ with probability at least $2/3$, in worst-case expected time $N^{1+o(1)}$; equal strings return zero deterministically.

Context

The unit-cost edit distance $\mathrm{ED}(x,y)$ is the minimum number of insertions, deletions and substitutions turning $x$ into $y$. For strings of total length $N$ with polynomially bounded integer symbols, the algorithm returns a nonnegative integer $\hat D$ with $\mathrm{ED}(x,y)\le \hat D\le (1+\varepsilon)\mathrm{ED}(x,y)$ with probability at least $2/3$; equal strings return $0$ deterministically. For every fixed rational $\varepsilon$, worst-case expected time is $N^{1+o(1)}$ on a logarithmic-word RAM, including input processing, preprocessing, numerical work, sampling and data-structure operations. The asymptotic is pointwise in $\varepsilon$: constants and thresholds may depend on $\varepsilon$. Exact computation is used below an accuracy-dependent length threshold, so the result is an asymptotic approximation scheme.

Relevance

Exact edit distance has a quadratic dynamic program and a strong subquadratic lower bound under SETH, so fixed $(1+\varepsilon)$ approximation in almost-linear expected time is a major advance. It makes large-scale string comparison, near-duplicate detection and alignment practical at fixed accuracy, with one-sided estimates $\hat D\ge \mathrm{ED}(x,y)$ and success probability amplifiable by independent repetitions. The construction uses recursive interval decompositions, predicted alignment bands, entropy-regularized refinement and lazy evaluation to bound total work.
