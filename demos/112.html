Beyond the square-root exponent for depth-three circuits (conceptual, result 112)

There is a single language in deterministic polynomial time whose \(n\)-bit membership function requires more than \(2^{A\sqrt n}\) total gates in unbounded-fan-in OR–AND–OR depth-three circuits for every fixed \(A>0) and all sufficiently large (n). Vary the input length, the target constant (A), a baseline square-root constant (c), and a polynomial degree to compare growth.

Context

The formalized result gives one polynomial-time Boolean language whose exact depth-three OR–AND–OR circuit size eventually exceeds \(2^{A\sqrt n}\) for every fixed \(A>0). The language and its polynomial-time algorithm are fixed before (A) is chosen, while circuits may vary with the input length. Gates have unrestricted finite fan-in and sharing, with free input negations and constants. The result does not assert a fixed exponent (n^{1/2+\varepsilon}) or a lower bound for unrestricted depth.

Relevance

This crosses the square-root-exponent threshold for explicit depth-three Boolean circuit lower bounds. It shows that an explicitly given polynomial-time language is not computable by depth-three circuits of size (2^{O(\sqrt n)}), since for every constant multiple of (\sqrt n) in the exponent the required size is eventually larger. It therefore separates this language from the depth-three circuit class at a super-square-root exponential scale, while leaving unrestricted depth and fixed fractional exponents outside the statement.
