The Global Spherical Shell conjecture (conceptual, result 060)

Every connected minimal compact complex surface of class VII with \(b_2>0) contains a global spherical shell (GSS): a holomorphically embedded neighborhood of the standard (S^3\subset \mathbb C^2\setminus\{0\}) whose complement is connected. Tune (b_2), minimality, and a trial shell to see when a valid GSS is forced and how the complement stays connected.

Context

Relevance

Turns a topological/differential condition (\(b_2>0\)) into a rigid geometric structure: a minimal class VII surface is not merely an abstract 4-manifold but contains a standard spherical shell, forcing it to be a Kato surface. This drives the classification of class VII surfaces, constrains their moduli and automorphism groups, and links complex-analytic invariants (canonical class, \(b_2\)) to a concrete blow-up model. It also distinguishes the \(b_2=0\) (Hopf) case from the \(b_2>0) case and underwrites boundedness statements for these non-Kähler surfaces.
