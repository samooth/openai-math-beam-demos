The Falconer distance conjecture (conceptual, result 073)

For a compact set \(E\subset\mathbb R^d\), the distance set is \(\Delta(E)=\{|x-y|:x,y\in E\}\). Falconer's conjecture: if \(\dim_H E>d/2), then (\Delta(E)) has positive Lebesgue measure. Build a self-similar set with dimension (s=\log m/\log(1/r)), sample it, and inspect the distance histogram against the threshold (d/2).

Context

Resolves the Falconer distance conjecture in every dimension (d\ge 2): every compact set (E\subset\mathbb R^d) with Hausdorff dimension greater than (d/2) determines a set of Euclidean distances of positive Lebesgue measure. The proof covers all dimensions uniformly, so the threshold (d/2) is the operative barrier: above it, the distance set is not merely nonempty but has positive one-dimensional Lebesgue measure. The Lean formalization records both the planar case and the all-dimensional statement.

Relevance

The conjecture is a central bridge between fractal geometry and geometric measure theory: it predicts that enough Hausdorff mass in (E) forces a continuum of distances, not just a sparse set. The threshold (d/2) is sharp in general, and crossing it turns a zero-measure (or empty) distance set into one with positive measure. This underpins distance-set problems, pinned-distance estimates, and the broader program relating dimension, energy integrals, and Fourier decay of measures. It also complements discrete Erdős distance results by giving a continuous, measure-theoretic counterpart.
