Hardness of coloring three-colorable graphs (conceptual, result 106)

It is NP-hard to color a three-colorable graph using any fixed number $c\ge 3$ of colors. More strongly, for every fixed $0<\delta<1/3$, a deterministic polynomial-time reduction from 3SAT produces simple unweighted graphs that are three-colorable in the satisfiable case and have no independent set of size $\delta n$ otherwise, where $n$ is the number of vertices.

Context

The three-colorability promise does not make coloring easy: deciding whether such a graph can be colored with any fixed $c\ge 3$ colors remains NP-hard. The stronger reduction creates a gap between independent-set sizes. In the satisfiable case the three color classes give an independent set of size $n/3$; in the unsatisfiable case every independent set has fewer than $\delta n$ vertices. Since $\delta$ can be chosen arbitrarily close to $1/3$, the gap between $n/3$ and $\delta n$ can be made arbitrarily small while still separating the two cases.

Relevance

This is a promise-problem hardness result with consequences for inapproximability of coloring and maximum independent set on restricted graph classes. It shows that even with a structural promise, constant-factor approximations and fixed-color colorings can remain NP-hard. The reduction is deterministic, polynomial-time, and outputs the complete adjacency matrix, so the hardness holds in the standard unweighted simple-graph model.
