Hyperkähler SYZ and projective-space bases (conceptual, result 041)

A compact irreducible holomorphic symplectic (IHS) manifold (X) and a holomorphic line bundle (L) with nonzero nef isotropic first Chern class (c_1(L)) determine a Lagrangian fibration via semiample (L). For a projective Lagrangian fibration with normal projective base, the base is projective space. Toggle the data below.

Context

Proves the strong hyperkähler SYZ conjecture: every holomorphic line bundle with nonzero nef isotropic first Chern class on a compact irreducible holomorphic symplectic Kähler manifold is semiample. It also proves that every projective Lagrangian fibration with normal projective base has projective space as its base, in every dimension and deformation type.

Relevance

Converts a nef isotropic line bundle into an actual Lagrangian fibration on any IHS manifold, and forces the base of a projective Lagrangian fibration with normal projective base to be projective space. This constrains possible fibration geometries uniformly across dimensions and deformation types.
